# 🚶‍♂️ Walkthrough: Room Manager Bot

Этот документ описывает процесс установки, настройки и использования бота для управления комнатой (Smart Dormitory).

## 1. Предварительные требования

- **Python 3.8+** должен быть установлен на вашем компьютере.
- Доступ к интернету для работы с Telegram API.
- Токен бота от [@BotFather](https://t.me/BotFather).

## 2. Установка

1. **Клонируйте репозиторий** (если еще не сделали этого) или откройте папку с проектом.

2. **Создайте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv venv
   # Активация:
   # Windows:
   venv\Scripts\activate
   # macOS/Linux:
   source venv/bin/activate
   ```

   ```bash
   pip install -r requirements.txt
   ```
   *Основные библиотеки: aiogram, aiosqlite, apscheduler, python-dotenv*

## 3. Настройка

1. Создайте файл `.env` в корневой директории (рядом с `main.py`).
2. Добавьте необходимые переменные:
   ```env
   BOT_TOKEN=ваш_токен
   ADMIN_ID=ваш_telegram_id
   GROUP_ID=id_группы_для_рассылки
   ```
   *`ADMIN_ID` нужен для команды /settask.*
   *`GROUP_ID` нужен для ежедневных уведомлений.*

3. (Опционально) Убедитесь, что `.env` и `room.db` добавлены в `.gitignore`.

## 4. Запуск

### Запуск через Python
```bash
python main.py
```
Вы должны увидеть сообщения о запуске БД и шедулера.

### Запуск через Bat-файл (Windows)
```bash
./run.bat
```

## 5. Использование

### Основные команды:

- **/start** — Регистрация в комнате (сохраняется username).
- **/status** — Список участников и их текущие задачи.
- **/leave** — Выход из комнаты.

### Команды администратора (только для ADMIN_ID):

- **/settask @username Текст задачи** — Назначить задачу пользователю.
  - Пример: `/settask @ivan Вынести мусор`

### Автоматические функции:

- **Ежедневная рассылка**:
  - Каждое утро (в 09:00) бот отправляет сообщение в `GROUP_ID`.
  - Выбирает одного дежурного ("звездного" участника) по очереди.
  - Показывает его текущую задачу.

## 6. Структура проекта

- `main.py` — Точка входа, команды.
- `database.py` — БД (SQLite), логика storage.
- `scheduler.py` — Планировщик ежедневных задач.
- `specs_v2.md` — Спецификация текущей версии.
- `room.db` — Файл базы данных.
