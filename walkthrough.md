# 🚶‍♂️ SMART-DORMITORY: Пошаговое руководство (Walkthrough)

Этот документ поможет вам быстро развернуть проект, запустить сервер, подключить эмулятор устройства и протестировать работу системы, включая интеграцию с Алисой.

---

## ✅ 1. Подготовка окружения

Убедитесь, что у вас установлен **Python 3.11+**.

1. **Создайте и активируйте виртуальное окружение** (рекомендуется):
   ```powershell
   # Windows
   python -m venv venv
   .\venv\Scripts\activate
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

Данный шаг установит `FastAPI`, `Uvicorn`, `Websockets`, `Pytest` и другие необходимые библиотеки.

---

## 🚀 2. Запуск сервера (Backend)

Сервер отвечает за API, управление WebSocket-соединениями и интеграцию с Алисой.

1. **Запустите сервер**:
   ```bash
   uvicorn main:app --reload
   ```

2. **Проверьте работу**:
   - Откройте браузер и перейдите по адресу: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).
   - Вы должны увидеть Swagger UI с доступными эндпоинтами.

---

## 🤖 3. Запуск эмулятора устройства

Чтобы не использовать реальное "железо" (ESP8266/ESP32) для тестов, мы используем Python-скрипт `mock_esp.py`, который полностью имитирует поведение лампы.

1. **Откройте новый терминал** (не закрывая сервер).
2. **Запустите эмулятор**:
   ```bash
   python mock_esp.py --device-id my_test_lamp
   ```
   *Вы можете запустить несколько копий скрипта с разными `device-id` для тестов множества устройств.*

3. **Что должно произойти**:
   - В консоли эмулятора появится сообщение: `Connected to server!`.
   - Эмулятор отправит приветственное сообщение (`device_hello`).
   - Сервер синхронизирует состояние (эмулятор получит `sync_state`).
   - Устройство начнет отвечать на `ping` от сервера (каждые 5 сек).

---

## 🎮 4. Сценарий тестирования (User Flow)

Теперь, когда сервер и устройство запущены, давайте поуправляем светом.

1. **Проверка статуса**:
   - Перейдите в Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).
   - Найдите метод `GET /api/devices`.
   - Нажмите "Try it out" -> "Execute".
   - В ответе вы должны увидеть ваше устройство `my_test_lamp` со статусом `online`.

2. **Включение света**:
   - Найдите метод `POST /api/devices/{device_id}/turn_on`.
   - Введите `device_id`: `my_test_lamp`.
   - Нажмите "Execute".
   - **Смотрите в консоль эмулятора**: там должно появиться сообщение `Turning Light ON...`.

3. **Выключение света (Offline)**:
   - Остановите скрипт `mock_esp.py` (Ctrl+C).
   - Подождите 15-20 секунд (время таймаута Watchdog).
   - Снова запросите `GET /api/devices`.
   - Статус устройства должен смениться на `offline`.

## 🟣 5. Тестирование интеграции с Алисой

Проект поддерживает протокол Yandex Smart Home. Мы можем протестировать процесс авторизации локально.

1. **Авторизация (OAuth2)**:
   - Перейдите по ссылке (эмуляция входящего запроса от Яндекса):
     [http://127.0.0.1:8000/api/alice/authorize?client_id=my-smart-home&redirect_uri=http://localhost&response_type=code&state=123](http://127.0.0.1:8000/api/alice/authorize?client_id=my-smart-home&redirect_uri=http://localhost&response_type=code&state=123)
   - Вы увидите простую форму входа. Введите любое имя пользователя (например, `shohruh`) и нажмите "Разрешить".
   - Вас перенаправит на `localhost` с параметром `code=...`. Это значит, что авторизация прошла успешно.

2. **Проверка устройств пользователя**:
   - Для полноценной проверки API Алисы требуются валидные токены, что проще делать через автоматические тесты или реальный навык, но вы можете проверить эндпоинт "Health Check":
   - `GET /v1.0/ping` -> Должен вернуть `{"status": "ok"}`.

## 🖥️ 6. Веб-Панель (Dashboard)

Теперь доступен красивый веб-интерфейс для управления.

1.  **Откройте**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
2.  **Возможности**:
    *   Визуальный мониторинг статуса (Online/Offline).
    *   Управление включением/выключением в один клик.
    *   Поддержка темной темы и анимаций.

---

## 🧪 7. Запуск автотестов

Для уверенности в надежности системы, прогоните полный набор тестов.

```bash
pytest
```

**Что проверяется:**
- Корректность работы HTTP API.
- Логика WebSocket (подключение, команды, пинг-понг).
- Интеграция с Алисой (OAuth2 потоки и JSON-ответы).
