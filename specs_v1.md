# 🤖 Dormitory Bot — specs_v1.md

## 1. Цель (Этап 1)

Сделать **простой Telegram-бот**, который:

- Регистрирует участников через команду `/start`
- Сохраняет данные пользователей в БД
- Работает **строго в одной конкретной группе**
- Поддерживает **ровно 4 участника**
- Позволяет освобождать место через `/leave`

Это **первый этап** — только база.  


---

## 2. Границы (Scope)

### Входит в этап
- Регистрация пользователей
- Удаление себя из списка (выход)
- Сохранение данных
- Просмотр списка участников

---

## 3. Логика

### Регистрация (/start)
1. Пользователь пишет `/start` **в группе**
2. Проверка: зарегистрирован ли пользователь?
   - **Нет**:
     - Если мест нет (4/4) → Ошибка "Комната заполнена"
     - Если места есть → Сохранить в БД, Ответить "Добро пожаловать"
   - **Да**:
     - Ответить "Вы уже в комнате"

### Выход (/leave)
1. Пользователь пишет `/leave`
2. Проверка: есть ли он в БД?
   - **Да**: Удалить из БД, Ответить "Вы покинули комнату"
   - **Нет**: Ответить "Вы и так не в комнате"

### Ограничение
- Максимум **4 участника**

---

## 4. Данные пользователя (БД)

Минимальный набор:

- `telegram_id` (PK)
- `full_name` (Имя Фамилия или Username, что есть)
- `joined_at` (время регистрации)

Никаких дополнительных полей.

---

## 5. Команды

### `/start`
- Регистрирует пользователя
- Работает только если участников < 4

### `/leave`
- Удаляет пользователя из списка
- Освобождает место

### `/status`
- Показывает:
  - Сколько участников зарегистрировано
  - Список участников (full_name)

---

## 6. Хранение данных

- **SQLite**
- Файл `room.db`

Обязательно:
- Данные **не должны теряться** при перезапуске бота

---

## 7. Правила валидации

- Один пользователь не может зарегистрироваться дважды
- Нельзя превысить лимит (4 человека)

---

## 8. Обработка ошибок

- Простые и понятные сообщения
- Игнорирование команд из левых чатов (опционально для v1, но желательно)

---

## 9. Технические требования

- Python
- aiogram 3.x
- Простая структура (можно 1-2 файла)

---

## 10. Готово, если

Этап считается завершённым, когда:
- 4 пользователя успешно регистрируются
- 5-й получает отказ
- `/leave` освобождает место
- `/status` показывает актуальный список
- После перезапуска данные остаются
