# 📡 SMART-DORMITORY: Desk Light Control

**Version:** MVP v2  
**Status:** 🟢 Stable

Система управления индивидуальным освещением рабочего стола в общежитии ("Умное Общежитие"). Позволяет управлять устройствами (ESP8266/ESP32) через центральный сервер, используя WebSocket для связи с устройствами и HTTP API для клиентов.

## 🚀 Возможности

- **Мониторинг в реальном времени**: Отслеживание статуса подключения устройств.
- **WebSocket протокол**: Двусторонняя связь с устройствами (Heartbeat, команды, обновление статуса).
- **HTTP API**: REST интерфейс для управления светом (Вкл/Выкл) и получения информации.
- **Эмуляция**: Встроенный скрипт `mock_esp.py` для имитации работы железа без физического устройства.
- **Тестирование**: Полное покрытие сценариев (API + WebSocket) через `pytest`.

## 🛠 Технологический стек

- **Язык**: Python 3.11+
- **Сервер**: FastAPI, Uvicorn
- **Связь**: WebSockets (Starlette)
- **Тесты**: Pytest, TestClient
- **Железо**: ESP8266 / ESP32 (Arduino Framework)

## ⚙️ Установка и Запуск

### 1. Установка зависимостей
Рекомендуется использовать виртуальное окружение.
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
uvicorn main:app --reload
```
Сервер запустится на `http://127.0.0.1:8000`.

### 3. Запуск эмулятора устройства
Для проверки работы без реального железа запустите эмулятор в отдельном терминале (или вкладке):
```bash
python mock_esp.py
```
Эмулятор подключится к серверу и будет реагировать на команды.

### 4. Запуск тестов
```bash
pytest
```

## 🔌 API Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/devices` | Получить список всех подключенных устройств |
| `GET` | `/api/devices/{id}` | Получить состояние конкретного устройства (ON/OFF) |
| `POST` | `/api/devices/{id}/turn_on` | Отправить команду на включение света |
| `POST` | `/api/devices/{id}/turn_off` | Отправить команду на выключение света |

## 📡 Протокол (WebSocket)

Обмен данными происходит в формате JSON.

**От устройства (Device -> Server):**
- `device_hello`: Регистрация при подключении `{ "type": "device_hello", "device_id": "...", "state": "..." }`.
- `state_update`: Уведомление об изменении состояния `{ "type": "state_update", "device_id": "...", "state": "..." }`.

**От сервера (Server -> Device):**
- `command`: Команда на выполнение действия `{ "type": "command", "action": "TURN_ON" }`.
