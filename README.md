# 🤖 Room Manager Bot (Stage 1)

Простой Telegram-бот для управления регистрацией в комнате (максимум 4 человека).

## 🚀 Функционал

- **/start** — Зарегистрироваться в комнате.
- **/leave** — Покинуть комнату (освободить место).
- **/status** — Показать список участников (1-4).

## 🛠 Установка и Запуск

1. **Создайте бота** в Telegram через [@BotFather](https://t.me/BotFather) и получите токен.
2. **Вставьте токен** в файл `.env`:
   ```env
   BOT_TOKEN=ващ_токен_тут
   ```
3. **Запустите бота**:
   - **Windows**: Запустите файл `run.bat` (дважды кликните).
   - **Console**: `python main.py`

## 📂 Структура

- `main.py` — Основной код бота (обработка команд).
- `database.py` — Работа с базой данных (SQLite).
- `verify_logic.py` — Скрипт для проверки логики (тесты без Telegram).
- `specs_v1.md` — Техническое задание.

## ⚙️ Требования
- Python 3.13+
- Библиотеки: `aiogram`, `aiosqlite`, `python-dotenv`
