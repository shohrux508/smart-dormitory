# Отчет о готовности к деплою в Railway

Код технически готов к запуску, но есть важные нюансы, которые нужно учесть для стабильной работы в продакшене.

## 📂 Добавленные файлы
Я добавил два файла, необходимых для Railway:
1.  **`Procfile`**: Указывает Railway, как запускать бота (`worker: python main.py`).
2.  **`runtime.txt`**: Фиксирует версию Python (3.11.0), чтобы окружение совпадало с локальным (насколько это возможно).

## 🔑 Переменные окружения (Environment Variables)
В панели управления Railway (вкладка Variables) необходимо добавить:

| Переменная | Обязательно | Описание |
| :--- | :--- | :--- |
| `BOT_TOKEN` | ✅ Да | Токен от @BotFather |
| `GROUP_ID` | ✅ Да | ID группы, куда бот будет слать ежедневные уведомления (начинается с `-100...`) |
| `ADMIN_ID` | ❌ Нет | ID администратора (ваш Telegram ID) для доступа к командам настройки |

## ⚠️ Критические замечания

### 1. База данных (SQLite) и потеря данных
Бот использует **SQLite** (`room.db`). В Railway файловая система **эфамерна** (временная). 
**Что это значит:** Каждый раз, когда вы делаете новый деплой или бот перезагружается, файл `room.db` удаляется и создается заново пустым. Все зарегистрированные пользователи и настройки пропадут.

**Решение:**
В Railway нужно создать **Volume** (Раздел хранения данных). 
1. Перейдите в настройки сервиса в Railway.
2. Найдите раздел "Volumes".
3. Добавьте volume с путем монтирования `/app/room.db` (или просто `/app` если хотите сохранять всё, но лучше конкретно).
   * *Примечание:* Так как `room.db` лежит в корне проекта, путь монтирования должен соответствовать рабочей директории. Обычно в Railway это `/app`. Если вы примонтируете volume в `/app`, он может перекрыть файлы кода. 
   * **Лучшее решение:** Измените путь к БД в коде на папку, например `data/room.db`, и монтируйте volume в `/app/data`.

### 2. Часовой пояс (Timezone)
Серверы Railway работают по времени **UTC (+0)**.
Планировщик (`scheduler.py`) использует системное время.
Если вы установите время `09:00`, бот пришлет сообщение в 9:00 по Лондону (это 12:00 по Москве).

**Решение:**
Добавьте переменную окружения `TZ` в Railway со значением вашего часового пояса, например:
`Europe/Moscow`
Это заставит бота работать в вашем локальном времени.
