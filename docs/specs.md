# spec.md — SMART-DORMITORY / Desk Light (Mini MVP)

## Goal
Система управления индивидуальным освещением рабочего стола в комнате общежития
через сервер и ESP-устройства.

## What we do
- ESP-устройство подключается к серверу по WebSocket
- Сервер принимает соединение устройства
- Сервер отправляет команду включения или выключения света
- Устройство управляет реле (ON / OFF)
- Состояние устройства отправляется обратно на сервер

## What we do NOT do
- Нет автоматизаций
- Нет сценариев
- Нет расписаний
- Нет датчиков
- Нет базы данных
- Нет полноценного UI
- Нет группового управления

## Inputs / Outputs
- Input:
  - WebSocket команды от сервера (`TURN_ON`, `TURN_OFF`)
  - HTTP-запросы для ручного управления
- Output:
  - управление реле на ESP
  - события состояния устройства (`ON`, `OFF`)

## Constraints
- Python 3.11
- FastAPI
- WebSocket
- ESP32 / ESP8266 (Arduino)
- Один сервер
- Одно устройство = один источник света

## Edge cases
- устройство отключилось от сервера
- потеря WebSocket соединения
- повторное подключение устройства
- неизвестная команда
- сервер недоступен

## Done when
- ESP успешно подключается к серверу
- команда TURN_ON включает свет
- команда TURN_OFF выключает свет
- сервер получает подтверждение состояния
