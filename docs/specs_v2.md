# specs_v2.md — SMART-DORMITORY / Desk Light (MVP v2)

## Goal
Расширяемая система управления индивидуальным освещением рабочего стола
в комнате общежития через сервер и ESP-устройства.

Система должна корректно работать без реального железа (через эмулятор)
и быть готовой к дальнейшему масштабированию.

---

## What we do

### Сервер
- Сервер принимает WebSocket-подключения от устройств
- Каждое устройство идентифицируется по `device_id`
- Сервер хранит текущее состояние устройств в памяти
- Сервер отправляет команды управления устройствам
- Сервер предоставляет HTTP API для управления и получения состояния

### Устройство (ESP / эмулятор)
- Устройство подключается к серверу по WebSocket
- Отправляет приветственное сообщение с `device_id` и начальным состоянием
- Слушает команды от сервера
- Управляет реле (ON / OFF)
- Отправляет подтверждение изменения состояния

### Тестирование
- Используется эмулятор устройства (`mock_esp.py`)
- Используются автоматические тесты (`pytest`)
- Проверяется HTTP API и базовая WebSocket-логика

---

## What we do NOT do

- Нет базы данных
- Нет авторизации
- Нет пользователей
- Нет автоматизаций
- Нет сценариев
- Нет расписаний
- Нет датчиков
- Нет UI / Web-интерфейса
- Нет групп устройств
- Нет сохранения состояния между перезапусками сервера

## Protocol (WebSocket)

### Сообщения от устройства

Приветственное сообщение:
```json
{
  "type": "device_hello",
  "device_id": "desk_light_1",
  "state": "OFF"
}
### Обновление состояния устройства:
{
  "type": "state_update",
  "device_id": "desk_light_1",
  "state": "ON"
}
```

### Сообщения от сервера

Команда включения:
```json
{
  "type": "command",
  "action": "TURN_ON"
}

```

Команда выключения:
```json
{
  "type": "command",
  "action": "TURN_OFF"
}

```


### HTTP API

#### 1. Список устройств
`GET /api/devices`

Ответ:
```json
[
  "desk_light_1",
  "desk_light_2"
]
```

#### 2. Получить состояние
`GET /api/devices/{device_id}`

Ответ (200 OK):
```json
{
  "device_id": "desk_light_1",
  "state": "ON"
}
```
Ответ (404 Not Found): Если устройство не подключено.

#### 3. Управление
`POST /api/devices/{device_id}/turn_on`
`POST /api/devices/{device_id}/turn_off`

Ответ (200 OK):
```json
{
  "device_id": "desk_light_1",
  "status": "command_sent"
}
```

Ответ (404 Not Found): Если устройство не подключено.

### Inputs / Outputs
Inputs

WebSocket-сообщения от устройств

HTTP-запросы управления

Outputs

WebSocket-команды устройствам

HTTP-ответы с текущим состоянием

### Constraints

Python 3.11

FastAPI

WebSocket (Starlette / FastAPI)

ESP32 / ESP8266 (Arduino)

Один сервер

Несколько устройств (логически)

Состояние хранится в памяти

### Edge cases

Устройство подключилось без device_id

Повторное подключение устройства с тем же device_id

Устройство отключилось от сервера

Потеря WebSocket-соединения

Команда отправлена, но устройство не подключено

Некорректное или пустое WebSocket-сообщение

Неизвестная команда

Сервер недоступен

### Done when

Сервер принимает WebSocket-подключения устройств

Каждое устройство корректно идентифицируется по device_id

Команда TURN_ON включает свет

Команда TURN_OFF выключает свет

Устройство отправляет подтверждение состояния

HTTP API возвращает актуальное состояние

Эмулятор полностью заменяет реальное ESP-устройство

Все тесты проходят
