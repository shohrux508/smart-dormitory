# 📡 SMART-DORMITORY Report
> **Status**: 🟢 Stable | **Version**: MVP v2 | **Date**: 2026-01-29

Тут собран полный слепок текущего состояния системы "Умное Общежитие" (Desk Light Control). Этот отчет служит отправной точкой для дальнейшего масштабирования и создания новых спецификаций.

---

## 🏗 Архитектура и Ядро
Система построена на **FastAPI** и использует гибридную модель взаимодействия: **HTTP** для клиентов (фронтенд/скрипты) и **WebSockets** для IoT-устройств.

### 🧠 Компоненты
| Компонент | Технология | Описание |
|-----------|-----------|----------|
| **Core Server** | `FastAPI` | Асинхронный сервер, маршрутизация, DI. |
| **Connection Manager** | `Python Class` | Управление WebSocket-сессиями, in-memory хранилище состояний. |
| **Protocol** | `JSON` | Унифицированный протокол обмена сообщениями (Hello, Update, Command). |
| **Testing** | `pytest` + `TestClient` | Интеграционные тесты API и WebSocket сценариев. |

### 🧬 Текущий Функционал (MVP v2)
- ✅ **Регистрация устройств**: Устройства подключаются по WS и шлют `device_hello`.
- ✅ **Живой мониторинг**: Сервер отслеживает разрывы соединений.
- ✅ **Синхронизация состояний**: Двусторонняя связь (Устройство -> Сервер -> Клиент).
- ✅ **HTTP API**:
    - `GET /api/devices/` — Кто онлайн?
    - `GET /api/devices/{id}` — Что с лампой?
    - `POST /api/devices/{id}/turn_on` — 💡 Включить!
    - `POST /api/devices/{id}/turn_off` — 🌑 Выключить!

## 📂 Структура Проекта
Ключевые файлы и их ответственность:

- **`main.py`** — 🧠 **Мозг**. Содержит `FastAPI` приложение, логику `ConnectionManager` и все эндпоинты.
- **`test_main.py`** — 🛡️ **Щит**. Тесты проверяют счастливые пути и обработку ошибок (404, разрывы).
- **`mock_esp.py`** — 🤖 **Симулятор**. Скрипт, притворяющийся умной лампой для локальной разработки.
- **`specs_v2.md`** — 📜 **Закон**. Текущая спецификация требований.
- **`requirements.txt`** — 📦 **Багаж**. Зависимости (`fastapi`, `uvicorn`, `websockets`, `pytest`, `httpx`).

## 📊 Состояние Протокола
Строго типизированный JSON обмен.

### 📥 Вход (Device -> Server)
```json
// Hello
{"type": "device_hello", "device_id": "esp32_01", "state": "OFF"}

// State Update
{"type": "state_update", "device_id": "esp32_01", "state": "ON"}
```

### 📤 Выход (Server -> Device)
```json
// Command
{"type": "command", "action": "TURN_ON"}
```
